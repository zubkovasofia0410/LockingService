# ---
The hardware-software system for protecting a computer from unauthorized access consists of two parts. The first part includes an assembly of a card reader based on Arduino. Communication with the computer is done via a COM port, with the reader connected to the PC through USB.
In Visual Studio, it is necessary to connect to the appropriate port to receive messages. The application itself runs as a Windows service, operating in the background and starting automatically when logging into the OS.
When a card is placed on the connected reader, its number is verified by the service—all stored card codes are kept in an encrypted file on the local computer. If the card ID is found, access to the Windows account is granted. Otherwise, the computer is immediately locked. Removing the card from the reader will also log the user out of the Windows account.
